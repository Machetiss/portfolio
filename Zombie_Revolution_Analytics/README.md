## 📌 О проекте (Business Context)
Анализ продуктовых, маркетинговых и финансовых метрик мобильной игры **Zombie Revolution**. 
**Цель проекта** — оценка успешности новых маркетинговых каналов, локализация технических сбоев и поиск точек роста для монетизации и удержания игроков.

## 🛠 Стек технологий и инструменты
* **СУБД:** PostgreSQL (оконные функции, CTE, агрегации, когортный анализ, работа с датами).
* **Аналитика:** MS Excel (построение сводных таблиц, визуализация DAU/WAU/MAU, расчет экономики).
* **Метрики:** DAU, WAU, MAU, Sticky Factor, K-factor (вирусность), ARPPU, Retention.

## 📂 Структура репозитория
* `sql_queries/` — скрипты с SQL-запросами к БД `skygame`.
* `visuals/` — графики и диаграммы (выгрузки из Excel).
* `presentation/` — итоговая презентация с рекомендациями для бизнес-заказчика.

## 📈 Ключевые результаты и инсайты

### 1. Вирусность и органический рост (K-factor)
Для оценки органического роста был рассчитан коэффициент вирусности (K-factor) и спрогнозирован размер будущих когорт.

```sql
WITH total_reg AS ( 
    SELECT sum(ref_reg) AS cnt_ref_reg 
    FROM skygame.users u
    LEFT JOIN skygame.referral r ON u.id_user = r.id_user
),
total_users AS (
    SELECT count(distinct id_user) AS cnt_total_users
    FROM skygame.users
)
-- Расчет K-factor через CROSS JOIN и прогнозирование когорт
```
**Бизнес-вывод:** K-factor = `0.92`. Игра пока не способна расти исключительно органически (без внешнего маркетинга). Выдана рекомендация бизнесу по пересмотру и усилению реферальной программы.

### 2. Локализация критических багов (Technical Issues)
Анализ логов игровых сессий показал наличие аномального количества незавершенных сессий (`end_session IS NULL`).

**Бизнес-вывод:** Выявлено, что почти **12% всех сессий** являются "битыми". При сегментации с помощью оконных функций по `dev_type` доказано, что проблема носит платформозависимый характер — **на iOS обрывается 19% сессий**, тогда как на Android всего 0.75%. Данные оперативно переданы мобильным разработчикам.

### 3. Эластичность спроса и монетизация (Monetization)
Проанализировано влияние поэтапного повышения цен на внутриигровую валюту (кристаллы подорожали с 34 до 56 единиц, рост +64.7%).

**Бизнес-вывод:** Повышение цен не вызвало оттока покупателей. Объем покупок вырос почти в **2.8 раза**, а число платящих игроков увеличилось с 81 до 198 человек в месяц. Экономика игры здоровая, имеется запас прочности для дальнейших прайс-тестов.
